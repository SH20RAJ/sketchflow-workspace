# sketchflow-workspace

This is a Sketchflow workspace.

Sketches, docs, exports, assets, and project metadata live in this repository so the workspace stays portable and versioned with Git.

Open the workspace in Sketchflow: https://sketchflow.shraj.workers.dev

## Structure

- `.sketchflow/` workspace manifests, indexes, and sync metadata
- `projects/` project sketches, docs, exports, and assets
- `projects/first-project/sketches/system-map.excalidraw.json` first Excalidraw scene
